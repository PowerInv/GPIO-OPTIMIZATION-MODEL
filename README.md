# GPIO-OPTIMIZATION-MODEL
An optimization model is established for GPIO mux function selection of TI‑series development boards.
## GPIO0-GPIO68_Pins.xlsx
It is the GPIO pin peripheral-mux table of the TI 28P55-series development boards, used specifically to mux the GPIOs into various peripheral pins. It is derived from the official reference manual of TI 28P55, and serves as the only input data required by users in this project.
